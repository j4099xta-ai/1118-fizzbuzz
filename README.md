# 1118-fizzbuzz

1〜50の範囲で FizzBuzz を視覚的に確認できるシンプルな Web ページです。

---

## 概要

本リポジトリは、HTML・CSS・JavaScript（Vanilla JS）のみで構築された単一ファイル完結型の FizzBuzz ビューアです。外部ライブラリへの依存はなく、ブラウザで直接開くだけで動作します。

---

## 主な特徴

- **単一ファイル完結**: `index.html` のみで構成されており、セットアップ不要で即座に動作します。
- **レスポンシブ・グリッドデザイン**: PC、タブレット、スマートフォンの画面幅に合わせてカードが自動で整列します。
- **視覚的なカラーコーディング**:
  - **FizzBuzz**（15の倍数）: バイオレット（特別アクセント）
  - **Fizz**（3の倍数）: スカイブルー
  - **Buzz**（5の倍数）: エメラルドグリーン
  - **通常の数値**: ニュートラルグレー
- **自動サマリー表示**: 全体件数（50件）および各判定結果の内訳件数をヘッダーのバッジで一覧表示します。
- **ダークモード対応**: OSの表示設定（ライト/ダーク）に応じて自動的に配色が切り替わります。

---

## FizzBuzz のルール

| 条件 | 表示 | 1〜50の内訳 |
| :--- | :--- | :--- |
| **3 と 5 の公倍数（15の倍数）** | `FizzBuzz` | 3 件（15, 30, 45） |
| **3 の倍数** | `Fizz` | 13 件（3, 6, 9, 12, 18, 21, 24, 27, 33, 36, 39, 42, 48） |
| **5 の倍数** | `Buzz` | 7 件（5, 10, 20, 25, 35, 40, 50） |
| **上記以外** | そのままの数値 | 27 件 |
| **合計** | - | **50 件** |

## 使い方

### 1. リポジトリのクローン
```bash
git clone https://github.com/j4099xta-ai/1118-fizzbuzz.git
cd 1118-fizzbuzz
```

### 2. 実行
Webサーバーの起動は不要です。`index.html` をお好みのブラウザで直接開いてください。

- **Windows**: エクスプローラーで `index.html` をダブルクリック
- **PowerShell**:
  ```powershell
  Start-Process index.html
  ```
